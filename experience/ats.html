My role

I contributed to the quality assurance of Middleware XL EDS, an intermediary application developed by ATS Digital for Chronopost (details in the "Project" section below). My responsibilities included:

  • Requirement analysis: analyzed specifications from the Product Owner and joined review sessions with developers to clarify requirements, spot inconsistencies and ensure testability.
  • Test design and execution: designed, maintained and executed manual test cases for UI, API, mobile and end-to-end testing, covering positive, negative and edge cases.
  • Test automation: developed and maintained automated end-to-end and API tests with Cypress, using Git for version control.
  • API testing: validated REST endpoints, request and response payloads, and status codes with Postman and Cypress.
  • Integration testing: checked that the middleware exchanges data correctly with the connected systems, including the Urbantz delivery platform and its mobile application.
  • Regression testing: tested early during development, confirmed bug fixes, and ran regression tests before releases.
  • Defect management: created bug tickets in Jira and worked with developers to investigate issues and validate fixes.
  • Agile Scrum: took part in sprint planning, daily stand-ups, sprint reviews and retrospectives.
  • Client demos: presented implemented features to the French client team and ATS Digital's Tunisian team, and gathered their feedback.
